#  json REST сервер с двумя ручками:

POST /edit/:Id - изменение новости по Id\
GET /list - список новостей\
БД - postgres

В качестве сервера использован fiber. Для работы с базой reform, а также golang-migrate для реализации миграций.
Для работы сервера требуется локально созданная база данных News. Не прописал ее создание.

## Сервис упакован в Docker контейнер, реализована пагинация, логирование, обработка ошибок

Для запуска требуется:
1. клонировать репозиторий
2. установить Docker Desktop
3. запустить в терминале командой "docker-compose up"
